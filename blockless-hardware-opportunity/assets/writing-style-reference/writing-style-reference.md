# Blockless 人味与愿景写作参考库

来源：10,000 条中文创作参考单元，来自公开 Apache-2.0 的 COIG-Writer；已做 24 簇文字特征聚类。平均单元长度 50.1 字，第一人称平均出现 0.39 次。该库提炼的是节奏、视角和结构，**不是句库，不可复制或仿写某一篇作品**。

## 写给创意发起人的十二个动作

1. **从一个小瞬间开门**：不要先说市场。先说“你是不是也有过某个晚上……”。
2. **让物件有温度**：不是“硬件终端”，而是“放在桌边、在你开口前安静亮一下的小东西”。
3. **先承认孤单，再谈未来**：被理解的体验比“赋能”“效率”更接近真实。
4. **把宏大愿景落在一天里**：问“明天早上会少哪一件麻烦”，而非“颠覆什么行业”。
5. **用‘也许’打开空间**：愿景不是预测。写“如果它成真，也许……”。
6. **让用户成为共同作者**：用“我们先一起弄清这一分钟”，不用“请完成任务”。
7. **一个段落只完成一件事**：看见、想象、怀疑、邀请，分别写。
8. **把数据翻译成人话**：不写“174 条信号”；写“我们翻过 174 个公开痕迹，看到有人想要陪伴，也看到很多人害怕被监听”。
9. **保留反对意见**：好的愿景会自己说“这里还不够好”。
10. **不把用户的脆弱变成转化按钮**：不制造焦虑，不暗示错过，不许诺被拯救。
11. **给小动作一个未来**：说明这个 5 分钟选择会让下一次研究更像为他而做。
12. **结尾留一扇门**：不要催促；写“如果你愿意，门已经在这里”。

## 推荐节奏

`一个具体时刻 → 一句看见 → 一段如果成真 → 一句诚实限制 → 一个很小的邀请 → 下一步的微光`

## 禁用的冷硬表达

- “当前阶段仅进行桌面证据收集。”
- “请完成场景确认任务。”
- “用户痛点强度不足。”

对应改写：

- “我们先不急着做它，先看看它该在你的一天里出现在哪一分钟。”
- “如果愿意，选一个你最希望它陪你度过的时刻。”
- “现在我们还没有遇见足够多和你一样的人；这不是坏消息，只是下一扇门还没打开。”
