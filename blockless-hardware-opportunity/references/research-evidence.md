# 研究与证据

## 来源与早期信号

优先使用品牌官网、产品文档、价格页、官方论坛/issue、众筹项目、标准/监管机构、召回/安全公告；再用 Reddit 的具体板块、Hacker News、GitHub issue/discussion、专业论坛、公开问答、产品评论。优先寻找重复抱怨、用户自制、替代/迁移、产品比较、价格询问、预订、维修/支持、复购或企业采购痕迹。

不要把单个帖子、众筹热度、点赞或搜索结果直接作为需求证明。

| 字段 | 内容 |
|---|---|
| community | 具体社区与板块，例如 `r/homeautomation`，不是“Reddit” |
| location | 帖子、issue、讨论串、产品页或搜索 URL |
| signal | 问题、替代、自制、价格/采购、使用/维修、比较之一 |
| evidence_level | 0–8 行为层级 |
| quote_or_summary | 不超过 30 个原文词或忠实摘要 |
| date | 发布/更新日与采集日 |
| limitation | 样本偏差、地域、身份或商业意图的不确定性 |

先按用户任务聚类，再按抱怨/替代/付费/支持信号聚类；输出簇记录数、不同社区数、代表链接、重复工作和反证，而不是只输出关键词频率。
