# 关键词与问题空间

将一句硬件创意扩展为可研究、可验证但不夸大的问题地图。

| 维度 | 要问的问题 | 关键词形式 |
|---|---|---|
| 用户与场景 | 谁在何时何地遇到问题？ | persona, job, context, role, workflow |
| 功能结果 | 用户想完成什么而非想买什么？ | outcome, avoid, monitor, carry, detect, automate |
| 现有替代 | 现在用什么凑合？ | workaround, DIY, manual, competitor, alternative |
| 产品形态 | 设备、配件、传感器、机器人还是工具？ | category, component, interface, form factor |
| 工程约束 | 电源、连接、材料、精度、环境与安全？ | battery, sensor, enclosure, wireless, compliance |
| 商业约束 | 谁付钱、多久使用、如何获得？ | buyer, budget, procurement, channel, repeat |

优先保留用户语言，例如“晚上找不到钥匙”优于“智能照明设备”；再映射产品语言，例如 `key finder`, `ambient light`, `home safety`。每组至少给出中英文同义词、否定词和竞品/替代关键词。
